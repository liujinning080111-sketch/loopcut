# 验证记录

日期：2026-10-21。以下记录描述本地开发环境中的实测结果，公网 GitHub Pages 发布情况需另行确认。

## 可复现检查

```sh
npm ci
npx playwright install chromium webkit
npm test
npm run test:e2e
```

`test:e2e` 会先执行 TypeScript 检查、生产构建与离线缓存清单生成，再启动生产预览服务；测试结束后关闭该服务。

| 检查 | 结果与实际覆盖 |
| --- | --- |
| 单元测试 | **19 / 19 通过**。运动候选、静态画面与不可信循环拒绝、完整循环、保留停顿、背景判断与边缘连通去底；GIF 编解码、透明与不透明黑色区分、disposal 2、无限循环、时间精度和输入上限。 |
| Chromium 浏览器 | **3 / 3 通过**。真实 MP4 导入、自动定位与 2 秒循环、预览像素、手动裁剪、矩形与透明 GIF、下载字节一致、设置变更使旧结果失效；解码及编码取消、损坏文件恢复；窄屏和离线。 |
| 桌面 WebKit＋iPhone 视口 | **3 / 3 通过**，执行相同工作流；使用 Playwright WebKit 27.2 与 iPhone 布局配置。 |
| 非整帧终点 | 15 fps 下手动选择 1.07 秒，导出 GIF 后实际解码总时长 **1070 ms**，没有因末帧过短而失败。 |
| 矩形导出 | 用已知画布坐标裁剪内置示例，解码确认首帧没有透明像素，总时长 **2000 ms**。 |
| 透明导出 | 实际 GIF 同时包含透明背景和不透明主体；每帧 disposal 2，总时长 **2000 ms**。 |
| 下载 | 下载的文件名以 `.gif` 结束，下载文件与预览 Blob 的字节完全一致。 |
| 响应式布局 | 390 × 844 视口，导入前、完成导出后均无横向溢出；截图已人工查看。 |

取消测试使用受控延迟，确保取消发生在视频读取或 Worker 编码尚未完成时，避免快速设备上的竞态使测试偶然通过。浏览器断言还监测页面未处理异常。

## GitHub Pages 仓库子路径

将完整生产 `dist/` 挂载在独立静态 HTTP 服务的 **`/loopcut/`** 下进行额外 Chromium 测试，不使用 Vite 的路径回退行为代替静态托管测试。

- 入口 HTML、相对路径 CSS 和主脚本成功加载；布局计算结果正确。
- GIF 模块 Worker 从 `/loopcut/assets/gif.worker-….js` 加载，返回 200。
- Manifest 与 192 / 512 PNG 图标、Apple touch icon 全部返回 200。
- Manifest `start_url`、`scope` 解析为 `/loopcut/`；Service Worker 脚本为 `/loopcut/sw.js`，注册范围为 `/loopcut/`。
- 缓存安装完成后切断浏览器网络，刷新应用仍成功；可以离线打开内置 MP4、自动定位循环，并完成 Worker 编码。
- 该子路径离线导出结果经独立 GIF 解码器检查：**20 个有效画面，2000 ms，217 × 213，94,085 字节**；包含透明像素。
- 页面未处理异常 0，失败请求 0。此项验证没有进行主屏幕安装或系统分享操作。

## 证据边界

1. **桌面 WebKit 模拟 iPhone 视口不等于 iPhone 真机验证。** 原生照片选择器、设备 HEVC 解码、低内存行为、iOS 系统分享、主屏幕安装、锁屏和长时间使用仍需按 [真机测试清单](DEVICE-TESTS.md) 验收。
2. 自动检测验证使用自行绘制的合成 MP4 和单元测试序列，**尚不能给出真实抖音录屏识别准确率**。滚动、多个运动区域、遮挡、复杂背景、只有半个循环时应检查置信度并使用手动修正。
3. 分享按钮按 Web Share 用户手势要求实现；网页不会静默写入照片图库。分享 Promise 成功也无法证明文件已存入照片。实际微信导入接受情况没有在本地浏览器测试中验证。
4. 本地生产构建、浏览器测试和子路径验证不会自动证明公网发布成功。还需要实际托管 URL、GitHub Actions 部署结果及公网访问确认。
