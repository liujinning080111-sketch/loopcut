# 内置录屏与测试素材

`public/demo.mp4` 是本项目自行绘制的合成录屏，用于无用户素材时演示完整导入、检测、裁剪和导出流程。没有使用抖音截图、商标、真实评论、用户头像或第三方表情素材，也不能据此推定真实抖音录屏的识别成功率。

## 已知真值

- 画面：1080 × 1920，竖屏；30 fps；总长 6 秒；180 帧；无音频。
- 编码：H.264 High Profile / Level 4.1 / yuv420p / MP4，CRF 18，faststart。
- 表情画布：原视频像素 `x=240, y=780, width=600, height=600`，矩形像素范围为 `(240, 780)` 至 `(839, 1379)`。归一化约为 `{ x: 0.222222, y: 0.40625, width: 0.555556, height: 0.3125 }`。
- 背景：纯白矩形，含完整留白边缘；画布外有静态的合成评论界面。
- 动作：黄色笑脸轻微上下运动并挥手，每周期眨眼一次。一个完整循环为 **2 秒 / 60 帧**，共重复三遍；每圈第 24–29 帧眨眼，保持原 15 fps 素材的 0.8–1.0 秒相位。GIF 提取应保留脸、脚和挥动的手，不能只截取运动最大的局部。
- 透明导出应移除与画布边缘连通的白色背景；矩形导出应保留白色背景。

自动检测采样只有 8 fps，结果允许约一个采样间隔的周期误差；不能把算法输出反向当作素材真值。手动裁剪上述画布并选取 `[0, 2)` 秒，可作为独立对照。

全部形状、线宽和字体在 1080 × 1920 画布上按三倍几何坐标原生绘制，字体使用 60 / 36 px。生成过程没有读取旧示例帧，也没有把 360 × 640 的位图插值放大。手动选择精确画布后，原画模式应保留 600 × 600 输出；细节验证需检查实际解码的 GIF，不能只看网页显示尺寸。

此高清示例替换了首版 360 × 640 / 200 px 表情素材。旧截图、示例 GIF 和历史验证记录描述的是生成它们时的旧素材，不能当作本次高清预览与导出已通过的证据；新结果需另行验证与记录。

## 重新生成

Python 生成工具是可选的测试素材开发依赖，不用于网页运行，不进入浏览器产物。

```sh
python3 -m venv .demo-venv
.demo-venv/bin/pip install Pillow==13.0.0 imageio-ffmpeg==0.6.0
.demo-venv/bin/python scripts/generate-demo.py
```

源代码完整保存在 `scripts/generate-demo.py`。图像和动作是确定性的；MP4 二进制可能随不同平台 FFmpeg 编译版本变化。脚本强制输出小于 1 MiB。正式体验与验收仍需使用用户授权的真实录屏，覆盖不同背景、尺寸、多个表情、滚动、半个循环、停顿、压缩噪声和不同 iPhone 机型。
