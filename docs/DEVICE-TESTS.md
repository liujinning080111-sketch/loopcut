## 代表性素材

| 素材 | 准备方式 | 核心目的 |
| --- | --- | --- |
| A：纯色评论背景、单个表情 | 固定画面，录至少三遍，带一次明显停顿；记录人工测出的周期 | 区域识别、周期、时间保持、透明建议 |
| B：有自身矩形底图的表情 | 录三遍，矩形内部包含图案、文字或渐变 | 智能模式保守保留矩形，用户可切换 |
| C：同色边缘 | 白色或浅色主体贴近白底，另含封闭白色眼睛 | 透明阈值误删检查、回退矩形 |
| D：多个运动区域 | 两个同时播放的表情，或顶部背景视频仍运动 | 候选区域选择、手动画框 |
| E：不完整 / 静止 | 分别录少于一遍、单张静止图 | 不应将缺失动作伪造为完整循环 |
| F：滚动或遮挡 | 含滑动、弹窗、手指菜单；另准备相同表情的稳定片段 | 低置信度提示、手动时间范围 |
| G：格式差异 | 真实 iPhone 录屏 MP4 / MOV；有条件时包含 HEVC 与 H.264 | 元数据、方向、首帧、解码错误路径 |
| H：资源压力 | 接近界面允许上限的素材，以及超出上限的素材 | 限制提示、取消、再次导入与恢复 |

优先用自己有权处理的表情或自制测试动画。保留人工参考的周期与应有裁剪框；否则“看起来顺滑”不能确认去重正确。

输出：GIF 尺寸、时长、帧数、大小、背景模式

保存结果后，请从“文件”或“照片”重新打开，再在微信中检查。分享 API Promise 成功、下载链接被点击、GIF 能在网页中播放，这三件事都不能单独证明照片已保存或微信已接收。
